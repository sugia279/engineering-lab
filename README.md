# Hien's Nha

Nhà của Hiển — kiến thức, dự án, tủ truyện, âm nhạc và sổ lưu bút. Vietnamese is the default interface; English is available through the VI / EN switch.

See [Hien's Nha organization and authoring guide](docs/hiens-nha.md) for the current navigation, bilingual pages, adding performances, guestbook moderation, file storage, database decisions and repository rename procedure.

The public repository is the canonical source for reviewed content. Obsidian publishing and NotebookLM export are future extension boundaries and are not part of the initial implementation.

See [01_Architecture.md](01_Architecture.md) through [09_DeploymentGuide.md](09_DeploymentGuide.md) and [ADR 0001](docs/decisions/0001-public-personal-knowledge-garden-and-knowledge-graph.md) for the approved design.
